Video Analyzer - Apple Silicon preview

Requires macOS 15 or newer on Apple Silicon. Premiere requires Premiere Pro 26.3+ and Creative Cloud. The Resolve preview requires Resolve Studio 20.1+ and a matching SDK bridge containing arm64; actual availability and compatibility of that native bridge still need verification on your Mac.

1. Drag Video Analyzer.app to Applications.
2. Install native Homebrew from https://brew.sh if it is not installed. Open Install FFmpeg.command to install FFmpeg and ffprobe. These tools are not bundled in this preview. Their license and source information is at https://formulae.brew.sh/formula/ffmpeg and https://ffmpeg.org/legal.html.
3. Open Prepare Premiere on Mac.command. Despite its existing name, this prepares the shared HTTPS endpoint for both Premiere and Resolve. It uses mkcert to prepare trusted HTTPS for localhost. macOS may request an administrator password. The app also offers this command through its menu bar. Only the public CA certificate is copied into the app's data folder; the private CA key stays in mkcert storage. Certificate and hostname verification remain enabled.
4. Open Video Analyzer.app. It stays in the menu bar and opens the analyzer in your browser at https://localhost:8443. Quit from its menu bar menu when finished.
5. Double-click VideoAnalyzer-Premiere-0.1.12.ccx to install the panel through Creative Cloud. Open it from Premiere's Plugins menu. Save your own Gemini key in analyzer Settings, then open the panel. It connects automatically to https://localhost:8443 without a pairing code.
6. For Resolve, close Resolve and choose Install Resolve integration from the app's menu bar, or extract the public VideoAnalyzer-Resolve-0.1.1.zip and open Install Resolve on Mac.command. Keep its VideoAnalyzer folder beside the helper. The helper copies WorkflowIntegration.node from your own installed Blackmagic SDK; that vendor module is excluded from this download. It refuses Intel-only bridges and Rosetta. Installation into /Library may need an administrator password.
7. Start the companion, restart Resolve Studio and choose Workspace > Workflow Integrations > Video Analyzer. It connects automatically without a pairing code. Load original Media Pool clips, choose Shots and tags or Full analysis, then click Analyze. Search shots/dialogue, select a source clip, copy file-relative ranges, export SRT, or add source markers to verified constant-rate originals. Exact source-viewer seeking and a documented marker undo transaction are unavailable in this preview.

This preview is ad hoc signed, not Developer ID signed or notarized. macOS may require normal approval in System Settings > Privacy & Security before opening it. Do not disable Gatekeeper. A signed and notarized public release is still pending.

Your database, thumbnails, imported uploads, settings and certificates are in ~/Library/Application Support/VideoAnalyzer. Removing the application does not remove that folder or your original media. Premiere and Resolve reference original source media rather than making a full import copy. Analysis is explicit and sends footage to Gemini through your configured key. Both Premiere and Resolve discover private local credentials automatically.

Automated companion build smoke tests use a temporary HTTPS certificate and isolated empty data. They do not install a CA or modify Keychain. Real Premiere and Resolve installation, SDK compatibility, source actions, marker behavior, and the setup interface still need testing on your Mac. Windows native testing used Resolve Studio 21.0.1 and a verified 24 fps test clip.
