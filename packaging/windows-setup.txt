Video Analyzer desktop preview

The installer includes the local analysis engine and browser interface. Python
and Node.js are not required on the user's machine.

FFmpeg is a separate prerequisite for video import and local frame analysis.
The installer offers to install Gyan.FFmpeg via Windows Package Manager (WinGet)
if the supported WinGet package is not found. Selecting this task authorizes the
third-party download and accepts the WinGet source/package license agreements.
Gyan's build uses GPLv3; license and source information are available at:
https://www.gyan.dev/ffmpeg/builds/
https://ffmpeg.org/legal.html

If WinGet is unavailable, install Microsoft's App Installer or run this later:

  winget install --id Gyan.FFmpeg --exact

Then quit and reopen Video Analyzer. The preview detects WinGet's FFmpeg folder.
Enter your own Gemini API key in the app's settings. No developer key is included.

Video Analyzer runs locally at http://127.0.0.1:8000 and opens your browser.
The system tray menu offers Open, Pair with Premiere, and Quit. Closing the
browser leaves the engine running; Quit stops it. Port 8000 must be available.

Premiere's UXP panel is included as a separate CCX plugin package. Use the Start
menu's "Install Premiere panel" shortcut to open Adobe's Creative Cloud plugin
installer. Premiere 26.3+ and Adobe Creative Cloud are required. This installer
does not install Adobe Premiere or silently load a plugin.

Saved analysis is stored in your Local AppData / VideoAnalyzer folder.
Uninstall removes the program only; saved data and original media are retained.

This preview installer is unsigned. A signed, self-contained public release and
macOS signing/notarization are still required before general distribution.
