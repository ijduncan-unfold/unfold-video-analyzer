Video Analyzer for DaVinci Resolve Studio - development preview

Requires Resolve Studio 20.1 or newer. The free edition does not support native Workflow Integration windows. This plugin uses Resolve's own Electron runtime and native WorkflowIntegration.node module; it needs no separately installed Node or Python runtime. The module is copied from your installed Blackmagic SDK during installation and is not included in this download.

Windows x64 first:
1. Install and run the updated Video Analyzer companion. Configure Gemini in its browser Settings.
2. Close Resolve. Double-click Install Resolve on Windows.cmd. It may request administrator permission to install in Resolve's shared plugin folder. If using the companion, its Start menu/tray also offers Install Resolve integration.
3. Restart Resolve Studio. Open Workspace > Workflow Integrations > Video Analyzer. It connects automatically to the local app; no pairing code is needed. If the app is closed, start it and the integration reconnects.
4. Select original local clips in the Media Pool, load the selection, choose Shots and tags or Full analysis, and click Analyze. Loading does not begin analysis.
5. Search shots or dialogue. Select clip selects the original in the Media Pool; Copy times and Open full analyzer provide review access. Add markers writes visible results to source clips; Export SRT saves all dialogue.

6. Select up to 50 analyzed shots. Save to Media Pool creates native subclips in Video Analyzer shots; drag these into your edit, append with Add to timeline, or create a New selects timeline. Each shot retains its own Keywords, Description and full analysis/dialogue in Comments. In Resolve 21 use Media Pool Metadata Search > Filter by All Fields. Original files are referenced, never copied. Verified constant-rate originals are required; review AI cut timing.

Apple Silicon Mac:
Use the updated native companion and its HTTPS setup. Close Resolve and open Install Resolve on Mac.command. The helper requires a native arm64-compatible bridge from your installed Resolve SDK. It refuses Intel-only bridges. Resolve itself supplies the plugin runtime. Connect to https://localhost:8443; certificate verification remains enabled. Install/setup may require an administrator password. Only native public companion builds are verified automatically; interactive Resolve behavior still needs acceptance on your Mac.

Markers use original-source frame offsets, not timeline timecodes. Verified constant-rate original clips are required for markers. Subclips, interpreted media, offline/relinked sources, occupied marker positions and stale project results are guarded. Marker batches preserve existing markers and attempt to roll back only their own additions on failure. Resolve does not expose a documented marker transaction/undo API or exact source-viewer seeking API in this preview.

Original media is referenced and never copied, renamed, or deleted. Analysis runs in the companion and persists when the plugin closes. The native integration discovers the running app through a private per-user file and authenticates automatically; credentials never enter the interface or saved preferences. Nonsecret project preferences persist separately. Visual match cuts remain in Open full analyzer.
