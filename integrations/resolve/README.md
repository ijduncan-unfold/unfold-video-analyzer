# Video Analyzer for DaVinci Resolve Studio

A native Workflow Integration window for **Resolve Studio 20.1+**, using the local Video Analyzer companion. Windows x64 comes first; the Mac path targets native Apple Silicon. The free edition does not support this Workflow Integration window.

Use **Sync metadata to Resolve** to apply the whole clip's mapped fields, searchable timed dialogue and complete structured analysis to the source Media Pool item. Saved individual shots also promote Scene, Shot, Take, Roll/Card, Camera #, Production Name, Director, DOP, Shot Type, Move and Location when available. Version **0.1.2** adds readable Comments and separate SDK third-party metadata fields for clip descriptions, timed dialogue, detailed analysis, slate readings, source inspection and complete analysis JSON. In the native Metadata panel, choose **All Groups** and read **Comments** for the labeled analysis. SDK third-party fields do not automatically create visible Custom columns. Existing editor values and manual revisions are preserved; conflicting slate readings remain in the record instead of being assigned to one clip field. See [the mapping and transcript/After Effects limits](../../docs/EDITOR_METADATA.md).

Use **Load Media Pool selection** for selected source shots, or **Load clip under playhead** for the video at the current timeline position. Timeline loading finds the full original recording in the Media Pool, including when the timeline uses a trimmed subclip; it does not read arbitrary highlighted timeline selections. Loading restores matching saved analysis without starting Gemini. **Reload saved results** refreshes the active project's registered sources. Choose **Shots and tags** or **Full analysis**, then **Analyze** when new analysis is needed. Search the **Clips** or **Transcript** tab, copy file-relative in/out times, export SRT, or add source markers to verified constant-rate originals.

Use **Add to timeline** on a clip, or select up to 50 clips and choose **Save to Media Pool**, **Add to timeline**, or **New selects timeline**. Add to timeline is disabled when no timeline is open; New selects timeline starts an edit. **Prepare to drag** on a clip saves a separate native subclip in **Video Analyzer shots**, referencing the original file without copying it. Drag saved subclips from that Media Pool bin into your edit; direct dragging from the integration window is not implemented. Timeline additions go to the end in source order, with available audio. Action feedback stays visible while scrolling, and unchanged background polls preserve cards and checkboxes.

Each subclip carries its own **Keywords**, **Description**, **Dialog Notes**, and **Comments**. Dialog Notes contain timed dialogue for the selected range. Comments retain readable and structured shot facts, human notes, overlapping dialogue, section analysis, and project context. Camera roll uses the native metadata key `Roll Card #`, translating older `Roll/Card` mappings automatically. In Resolve 21, open Media Pool search, choose **Metadata Search**, then **Filter by → All Fields** to search this data. Repeat saves reuse the same source range and preserve human metadata edits. Shot exports require verified constant-rate originals; AI cut boundaries still need editorial review.

Readable slate fields also travel with the shot. Production title, scene, take, camera roll, and credited crew are added to its keywords; Comments retain the complete reading and original visibility times. These are unreviewed visual readings and do not overwrite the original clip's native metadata or technical timing.

Use **Install Resolve integration** from the companion's Windows Start menu/tray or Mac menu bar. The standalone public ZIP also includes **Install Resolve on Windows.cmd** and **Install Resolve on Mac.command**. Install with Resolve closed, start the companion, then open **Workspace → Workflow Integrations → Video Analyzer**. The integration connects automatically; there is no pairing code to copy. Windows uses `http://127.0.0.1:8000`; Mac uses the trusted local endpoint `https://localhost:8443`. If the companion is closed, the window waits and reconnects when it starts.

The installer copies `WorkflowIntegration.node` from your own matching Blackmagic SDK. This vendor module is never redistributed in the public ZIP or companion. Windows requires the x64 module; Mac requires a bridge containing arm64 and refuses Intel-only modules. Resolve supplies Electron, so the plugin needs no separately installed Node.js runtime.

Original media is referenced and preserved. Saved analysis stays in the companion; plugin clip/search preferences persist per Resolve project. The native main process discovers the running app through a private per-user file and authenticates behind the scenes. Credentials never enter the interface or saved preferences. Analysis is explicit and billable through the configured Gemini key.

Times are measured from the beginning of the original file. **Show source in Media Pool** reveals its bin and selects the source item. **Go to timeline** prefers a saved subclip with the matching analyzed range, then falls back to the first source occurrence that covers the range; it does not highlight a timeline selection or claim exact cue positioning in retimed footage. Exact source-viewer seeking remains unavailable. Marker writes preserve existing markers and attempt careful rollback of their own additions if a batch fails. This preview has no documented native marker transaction/undo API, and AI timing remains approximate.

The implementation has automated backend, host, panel, and packaging checks. Windows native testing in Resolve Studio 21.0.1 verified the Workspace menu, searches, selection, subtitles, guarded source markers, persistence, project switching, and shutdown on an isolated 24 fps fixture. A separate native acceptance round verified automatic connection, panel close/reopen, waiting while the companion is stopped, and automatic reconnection after restart. Mac SDK compatibility and native Mac operations remain pending. See [installation, paths, limits, and native acceptance](../../docs/RESOLVE_HANDOFF.md).

Run the portable integration tests without Resolve or its SDK:

```sh
node --test integrations/resolve/tests/*.test.cjs
```
